# Сударь Барбершоп — Nuxt 4

Четыре страницы исходного сайта перенесены в Nuxt 4 с сохранением стилей,
контента, фотографий и адаптивной вёрстки. Навигация использует файловый роутинг
Nuxt и штатный `pageTransition`.

## Запуск

Требуется Node.js 24.15+ (точная проверенная версия записана в `.nvmrc`).

```sh
nvm install
nvm use
npm ci
npm run dev
```

Сайт доступен на `http://localhost:3000`. Маршруты: `/`, `/services`, `/gallery`,
`/contacts`. Ручного списка маршрутов для prerender нет.

## Проверка и сборка

```sh
npm run typecheck
npm run build
npm run preview
```

`build` создаёт серверную сборку в `.output`; `preview` запускает её локально.
Для статического хостинга используйте `npm run generate`: Nuxt автоматически
обходит страницы и создаёт `.output/public`.

Браузерные проверки требуют Chromium и запущенный сайт:

```sh
npx playwright install chromium
npm run dev -- --port 4173
# В другом терминале:
npm test
```

Для проверки другого адреса задайте `TEST_BASE_URL` (например,
`TEST_BASE_URL=http://localhost:3000/ npm test`). При необходимости можно указать
установленный Chromium через `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`.
Проверки покрывают HTML и метаданные, переходы без перезагрузки, историю браузера,
фильтры галереи, просмотр фото с клавиатуры, мобильное меню и повторное открытие карты.

## GitHub Pages

Workflow `.github/workflows/deploy.yml` выполняет проверку типов и статическую
генерацию, затем публикует `.output/public` в ветку `gh-pages`. Сохранён адрес
размещения `/barbershop/`: он задаётся переменной `NUXT_APP_BASE_URL` только при
сборке. Для другого репозитория или домена измените эту переменную в workflow.
В настройках GitHub Pages источником публикации должна быть ветка `gh-pages`.

## Структура

- `app/pages/` — главная, услуги, галерея, контакты.
- `app/layouts/default.vue` — общая навигация и мобильное меню.
- `app/components/` — карточки услуг, галерея, просмотр фото, карта и иконки.
- `app/data/site.ts` — исходные услуги, цены, фотографии и ссылки.
- `app/assets/css/styles.css` — исходные стили и анимация страниц Nuxt.

Шрифты Google Fonts, изображения Unsplash и карта Яндекса используют те же
внешние источники, что и оригинал. Конструктор карты подключается только в
браузере и заново инициализируется при открытии страницы контактов.
